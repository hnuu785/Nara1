# 나라장터 자체입찰 공고 법령 위반사항 모니터링 AI 경진대회

공공기관 자체입찰 공고의 공고문, 첨부 문서, 나라장터 등록 정보(메타데이터)를 종합 검토하여 24개 법령 위반 항목을 판정하고 판단 근거 문구를 추출하는 AI 추론 파이프라인 프로젝트입니다.

---

## 📌 프로젝트 개요

- **대회명**: 나라장터 자체입찰 공고 법령 위반사항 모니터링 AI 경진대회
- **목표**: 1건의 입찰공고 데이터를 입력받아 24개 항목의 법령 위반 여부(`0`/`1`)와 해당 근거 문구(원문 부분문자열)를 산출
- **평가 지표**:
  - **1차 (정량)**: 24개 항목 양성(위반=1) 클래스의 단순 평균 **Macro F1**
  - **2차 (정성/검증)**: 정량 80% + 근거 문구 정성평가 20% 및 규칙/재현성 검증
- **추론 환경**:
  - GPU: NVIDIA L40S 1대 (가용 VRAM 약 44.7GiB)
  - 고정 LLM: `google/gemma-4-26B-A4B-it` (vLLM offline API)
  - 보조 임베딩 모델: `BAAI/bge-m3`
  - 제약: 인터넷 차단(추론 시점), 파인튜닝 가중치/LoRA 반입 금지, 2시간 이내 추론 완료

## 🚀 빠른 시작 (Quick Start)

### 1. 개발 환경 설정
Python 3.10+ 환경에서 필요한 패키지를 설치합니다.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r submit/requirements.txt
```

### 2. 파이프라인 검증 (Mock 실행)
모델 가중치를 로드하지 않고 입력 로드, 전처리, 프롬프트 구성, 제출 파일 포맷 생성을 빠르게 검증합니다.

```bash
python3 submit/script.py --mock
```
실행 결과는 `output/submission.csv`로 저장되며, CSV 헤더와 형식 유효성이 자동 검증됩니다.

### 3. 로컬 샘플 추론 실행
vLLM 및 모델이 준비된 환경에서 소량의 샘플을 대상으로 실행할 수 있습니다.

```bash
python3 submit/script.py --limit 10
```

## 📦 제출 파일 패키징 (Packaging)

대회 제출 규격(최상위에 `script.py` 위치, 2GB 이하, 불필요 파일 제외)에 맞춰 ZIP 파일을 생성합니다.

```bash
# 기본 생성: submit_YYYYMMDD_HHMMSS.zip 및 submit.zip 동시 생성
python3 package.py

# 날짜 기준 명명: submit_YYYYMMDD.zip
python3 package.py --date-only

# 사용자 지정 파일명
python3 package.py -o my_submission.zip
```

- `package.py`는 `__pycache__`, `.DS_Store`, `.git`, `output/` 등을 자동 제외하고 필수 파일 존재 및 용량을 검증합니다.

## 📝 제출 파일 형식 안내

- **출력 경로**: `output/submission.csv`
- **열 구성 (49열)**: `id, v1..v24, e1..e24`
- **값 규칙**:
  - `v1`~`v24`: 정수 `0` 또는 `1`만 허용 (`true`/`false`, 공란, 문자열 `"1"` 불가)
  - `e1`~`e24`: 제공된 문서에 존재하는 **원문 부분문자열** (최대 500자, 비위반 시 빈칸)
  - 근거 문구가 `=`, `+`, `@` 등으로 시작하지 않아야 함 (CSV 수식 삽입 방지)
  - 인코딩: UTF-8, NFC 정규화, BOM 없음
