# 대회 판정에 쓰는 고시금액

대회 운영진의 [법령패키지 보완 공지](https://dacon.io/en/competitions/official/236754/talkboard/417908)는 다음 금액을 **대회 제공 자료**로 명시했다. 따라서 이 대회에서는 공고일별 과거 고시를 외부에서 조회해 바꾸지 않고, 제공된 법령 패키지와 이 보완 공지의 기준을 사용한다. 비교 대상은 부가가치세를 제외한 **추정가격**이다.

| 지방계약 지역제한 v5·v6·v7 유형 | 기준금액 |
|---|---:|
| 시·도 발주 물품·일반용역(세종특별자치시 제외) | 350,000,000원 |
| 교육청·학교, 지방공기업 발주 물품·일반용역 | 500,000,000원 |
| 세종특별자치시, 시·군·구 발주 물품·일반용역 | 500,000,000원 |
| 건설기술·설계/감리·엔지니어링기술 용역 | 330,000,000원 |
| 안전점검·정밀안전진단 | 150,000,000원 |

국가계약 물품·용역의 고시금액은 제공 법령 패키지 기준 **230,000,000원**이다. v2·v14~v16을 지방계약 지역제한 금액과 혼동하지 않는다.

001~100 중 실제 존재하는 90건에서 `004`는 학교 발주 일반용역이고 입찰추정가격이 243,560,464원이므로, v5의 5억원 기준에 미달한다. `055`는 단가계약이며 메타의 42,220원이 전체 추정가격이 아니므로 총액 확인이 필요해 보류했다. 금액 미달은 v5의 해당 없음만 뜻하며, v6·v7은 각각 별도 요건을 검토한다.
