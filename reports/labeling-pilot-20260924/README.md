목적: 특정 공고의 답을 암기하는 대신 다른 공고에도 적용할 수 있는 조건·예외·증거 기준을 정합니다. 11개 공고의 12개 항목을 검토합니다.

## 검토 순서

1. `review-answers.md`의 질문과 연결된 `cases/` 원문을 읽고 먼저 판단을 기록해 주세요.
2. 판단 근거는 동봉한 `provided-data/법령패키지/`만 사용하고 파일명·조문·단서까지 적어 주세요. 최신 인터넷 법령이나 외부 공고는 추가하지 않습니다.
3. 문서에 없는 사실은 가정하지 말고, 자료만으로 확정할 수 없으면 `보류`로 기록해 주세요. 보류는 검토용이며 최종 제출값이 아닙니다.
4. 독립 판단을 적은 다음 `comparison-after-review.md`를 열어 배포 정답과 비교해 주세요. 차이가 있으면 정답을 임의 수정하지 말고 해석 차이 또는 자료 부족으로 기록합니다.
5. 위반 여부만 적지 말고 동일 항목의 적용 조건과 예외를 한두 문장으로 적어 주세요. 이후 자동 라벨링 명세에 반영합니다.
